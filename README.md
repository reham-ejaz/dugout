Dugout_XI
Fantasy Cricket Team Builder & League Manager

Dugout_XI is a Python-based application for creating fantasy cricket teams, checking team selection rules, and managing a fantasy league.

Features
1. Load and manage cricket players using CSV files.
2. Create fantasy teams with captains and vice-captains.
3. Calculate team credits and player distribution.
4. Validate teams and report rule violations.
5. Manage leagues and display league tables.

Technologies
Python
Object-Oriented Programming (OOP)
CSV File Handling
